## KGOS.Code―KGOS関連プログラム集

KGOS.Codeでは、鹿児島大学が推進する全学イニシアティブ[「KGOS｜鹿児島オープンサイエンス－鹿児島の知×地×智を結ぶ」](https://www.lib.kagoshima-u.ac.jp/kgos/)の推進に関連して、鹿児島大学附属図書館オープンサイエンス研究開発部門にて開発された各種ツールのプログラムと関連資料を、公開・提供しています。

### 利用方法

KGOS.Codeのディレクトリに、KGOSツールのプログラムがそれぞれに格納されています。
各ディレクトリのREADMEファイルにて、①当該KGOSツールの目的と基本機能、②同ツールのインストール方法などをご確認の上、ご自由にご利用下さい。利用・改変・再配布は自由です。
ただし、KGOS.Codeにて公開されているプログラムの利用により被られたいかなる損失について、当該ツールの管理者KGOS-Promotionは責任を負いません。

本リポジトリにおけるソフトウェアを利用した研究成果を公表する場合、またはソフトウェアを改変して再配布する場合には、各サブディレクトリのREADMEをご参照のうえ適切な出典の明記にご協力をお願いいたします。
