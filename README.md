## KGOS 公開リポジトリ

鹿児島の「知」と「地」と「智」を結び、よりよい地域の実現につなげるイニシアティブ「KGOS」の公開リポジトリです。

本リポジトリでは、当部門の研究成果として開発したプログラムおよび関連資料を公開しています。
研究・教育活動の発展に資することを目的として、利用・改変・再配布を許可しています。

### 引用のお願い

本リポジトリにおけるソフトウェアを利用した研究成果を公表する場合、またはソフトウェアを改変して再配布する場合には、各ソフトウェアのREADME.mdをご参照のうえ適切な出典の明記にご協力をお願いいたします。
